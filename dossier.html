00 What this workspace does

TRACEABLE DECISION SUPPORT

Mission Dossier turns a selected Earth–Moon or Earth–Mars pair into a substantive technical report. It combines terrain products, source metadata, weather-model context, analogy audit results, dynamic-process analysis, and optional user comments when those inputs are available.

Discovery candidates are exploratory geometry matches generated from the published search grid; they are not verified field-test sites. Every dossier keeps unavailable evidence explicit instead of filling gaps with assumptions.

Primary sources include Microsoft Planetary Computer for Earth terrain and satellite products, Meteomatics for weather-model context, and the NASA/USGS planetary products named in each selected scenario.
